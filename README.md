# JettTime - Premium Travel Website

A stunning, modern travel website built with Next.js, Tailwind CSS, and Framer Motion featuring smooth animations, parallax scrolling, and professional design.

## 🎨 Features

- ✨ 56+ Premium Animations (parallax, 3D transforms, scroll-triggered)
- 🎭 Glassmorphism Design
- 🌈 Beautiful Gradient Effects
- 📱 Fully Responsive
- 💰 Indian Rupee Pricing
- ⚡ Production Ready

## 🚀 Quick Start

```bash
npm install
npm run dev
# Open http://localhost:3000
```

## 📦 Build

```bash
npm run build
npm start
```

## 🛠️ Tech Stack

- Next.js 16.2.12
- React 19.2.8
- Tailwind CSS 4.3.3
- Framer Motion 12.43.0
- TypeScript
- React Hook Form

## 🎨 Customization

### Change Colors
Edit `tailwind.config.ts` to modify the color scheme.

### Change Images
Replace Unsplash URLs in components with your own images.

### Change Prices
Edit prices in `components/TravelPackages.tsx` - all in Indian Rupees (₹).

## 🚀 Deployment

Deploy to Vercel:
1. Push to GitHub
2. Go to vercel.com
3. Import your repository
4. Deploy!
