## 🎨 Design System

### Colors
```
Primary: #FF6B6B (Coral Red) - Main actions & highlights
Secondary: #4ECDC4 (Teal) - Secondary elements
Accent: #FFE66D (Yellow) - Special highlights
Dark: #1a1a1a (Background)
Light: #f9f9f9 (Text)
```

### Animations
- Fade-in animations (0.5-0.8s)
- Slide-in animations
- Scale animations
- Hover effects (scale 1.05)
- Parallax scrolling
- Auto-play carousels
- Staggered animations

### Typography
- Brand font: System fonts (Segoe UI, Tahoma, Geneva, Verdana)
- Heading sizes: 3xl to 8xl
- Weights: Regular (400) and Bold (700, 900)
- Smooth scroll behavior enabled

- **Mobile**: 0px - 640px
- **Tablet**: 640px - 1024px
- **Desktop**: 1024px+

## 🚀 Technologies Used

### Core
- **Next.js 16** - React framework
- **React 19** - UI library
- **TypeScript** - Type safety

### Styling
- **Tailwind CSS 4** - Utility-first CSS
- **PostCSS** - CSS transformation

### Animation
- **Framer Motion 10** - Animation library

### Form
- **React Hook Form 7** - Form validation
- **Axios 1.6** - HTTP requests
